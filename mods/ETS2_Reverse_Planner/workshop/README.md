# Steam Workshop package

Before uploading:

1. Run `tools/PrepareWorkshop.ps1` to recreate `workshop/160_content` from `src/mod`.
2. Select this `workshop` directory in SCS Workshop Uploader.
3. Use `../assets/workshop_cover_640x360.jpg` as the preview image.
4. Set the public title exactly to `ReversePlanner (beta) For 1.60.x`.

The `160_content` directory is generated and excluded from Git.
