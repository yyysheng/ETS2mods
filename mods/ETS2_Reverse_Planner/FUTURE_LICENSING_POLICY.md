# Prospective licensing policy

No proprietary license is active. Any future change requires an explicitly approved new release, immutable commit and published scope identifying the rights holder and covered files/portions.

Eligible original code includes code for which the rights holder has full authority to relicense, EVEN IF that same original code was previously published under MIT. The future proprietary scope is not limited to new or newly added code. A later proprietary distribution cannot revoke or narrow previously granted MIT rights for historical copies. Historical MIT covered the original project code within its then-applicable scope, not only third-party components.

Third-party code and contributions lacking sufficient relicensing authority cannot be claimed as exclusively proprietary original code. Mixed files require explicit attribution and scope boundaries. Models and textures require independent ownership and historical-grant review; historical asset terms remain unresolved and are not retroactively designated MIT or proprietary.

Private evidence, approval records and inactive detailed contract drafts are maintained outside this public repository. They are not build inputs. Once a future switch is approved, its effective public license, scope and release-specific packaging profile must be reviewed together. Current packaging supports only the historical-MIT profile and fails closed for other modes.

This policy does not modify historic Git tags or grants. ETS2 v0.6.0 is outside this remediation and is not a basis for inferring inheritance.
