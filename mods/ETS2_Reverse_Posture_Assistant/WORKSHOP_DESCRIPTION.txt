[h1]v0.10.10 — Tyre-based slope and prediction update / 轮胎坡度与预测算法更新[/h1]
[b]Please update both the Workshop content and the native runtime. / 请同时更新工坊资源与运行组件。[/b]

[h1]English[/h1]
Reverse Posture Assistant adds world-space reverse guidance: two blue tractor boundaries and two orange trailer boundaries over a fixed 5 m prediction path. The curves follow steering and articulation, using wheel contact, lift state and steerable axle angles. Prediction lines appear only in reverse gear and hide while paused.

[b]What changed in v0.10.10[/b]
[list]
[*]Fits road pitch/roll from grounded tyre geometry, so unequal suspension height on level ground no longer tilts the guide.
[*]Uses measured front-wheel angle, lateral fifth-wheel offset and independent trailer equivalent-axle steering.
[*]Debounces lift/lower transitions for 400 ms and commits the stable axle geometry atomically.
[*]Keeps the v0.10.9 original trailer-marker restoration and verified 1.60 hook safety checks.
[*]Remains compatible with the separate Reverse Planner; this update does not modify its DLL, hooks or green guide resources.
[/list]

[b]Installation / upgrade[/b]
1. Exit ETS2 and let Steam download this item's latest content.
2. Download v0.10.10 Runtime for Workshop, extract it and run Install-Runtime-Only.bat.
[url=https://github.com/yyysheng/ETS2mods/releases/download/reverse-posture-assistant-v0.10.10/ETS2_Reverse_Posture_Assistant_v0.10.10_Runtime_for_Workshop.zip]Download Runtime for Workshop v0.10.10[/url]
3. Enable this Workshop item in the Mod Manager. Disable older local copies of Reverse Posture Assistant so they cannot override the restored game marker. Restart the game.

[b]A Workshop subscription alone cannot install the required DLL. Updating the DLL alone cannot remove the old marker override in an outdated mod package.[/b]
For standalone installation, use the Full package instead of subscribing; do not enable both copies:
[url=https://github.com/yyysheng/ETS2mods/releases/tag/reverse-posture-assistant-v0.10.10]v0.10.10 downloads and release notes[/url]
If Steam hides the link, search GitHub for yyysheng/ETS2mods and open Releases.

Compatibility: ETS2 1.60.*, Windows x64, with a verified native hook layout. ETS2 1.60.1.7 was checked locally. This release does not claim 1.61 compatibility. No camera, mirror, depth-buffer or rendered-image capture; no bundled dxgi.dll or d3d11.dll. No Reverse Assist Anchor accessory installation is required.

[h1]中文[/h1]

[b]v0.10.10 更新[/b]
[list]
[*]坡度改由接地轮胎几何拟合；平地前后或左右悬挂高度不同时，轨迹线不再被车身姿态带斜。
[*]使用实际前轮角、横向鞍座偏移及挂车独立等效轴转角。
[*]提升/落轴接地状态稳定 400 ms 后再原子提交轮组几何，避免动画过程抽动。
[*]保留 v0.10.9 的原游戏挂车指引框修复和已验证的 1.60 Hook 安全检查。
[*]继续兼容独立 Reverse Planner；本次不修改其 DLL、Hook 或绿色引导资源。
[/list]
