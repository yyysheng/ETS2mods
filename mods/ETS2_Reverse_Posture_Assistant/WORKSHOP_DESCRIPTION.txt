[h1]English[/h1]
Reverse Posture Assistant adds world-space reverse guidance: two blue tractor boundaries and two orange trailer boundaries over a fixed 5 m prediction path. The curves follow steering and articulation, using wheel contact, lift state and steerable axle angles. Prediction lines appear only in reverse gear and hide while paused.

[b]What changed in v0.11.0[/b]
[list]
[*]Adds ETS2 1.61.x package compatibility; native rendering was verified with the 1.61.1.0 Steam public executable.
[*]Updates the four native hook locations and model-creation helpers for the verified 1.61.1.0 build.
[*]Keeps the v0.10.10 tyre-ground slope fit, measured steering and articulated five-metre prediction.
[*]Preserves the original game trailer marker and safe telemetry-only fallback for unverified executable builds.
[*]Keeps Reverse Planner separate; its green route guide needs its own 1.61 runtime update.
[/list]

[b]Installation / upgrade[/b]
1. Exit ETS2 and let Steam download this item's latest content.
2. Download v0.11.0 Runtime for Workshop, extract it and run Install-Runtime-Only.bat.
[url=https://github.com/yyysheng/ETS2mods/releases/download/reverse-posture-assistant-v0.11.0/ETS2_Reverse_Posture_Assistant_v0.11.0_Runtime_for_Workshop.zip]Download Runtime for Workshop v0.11.0[/url]
3. Enable this Workshop item in the Mod Manager. Disable older local copies of Reverse Posture Assistant, then restart the game.

[b]A Workshop subscription alone cannot install the required DLL. Update the runtime DLL and Workshop content together.[/b]
For standalone installation, use the Full package instead of subscribing; do not enable both copies:
[url=https://github.com/yyysheng/ETS2mods/releases/tag/reverse-posture-assistant-v0.11.0]v0.11.0 downloads and release notes[/url]
If Steam hides the link, search GitHub for yyysheng/ETS2mods and open Releases.

Compatibility: ETS2 1.61.* and 1.60.*, Windows x64. Native rendering on 1.61 is verified for the exact 1.61.1.0 Steam public executable; other unverified builds safely use telemetry-only mode. No camera, mirror, depth-buffer or rendered-image capture; no bundled dxgi.dll or d3d11.dll. No Reverse Assist Anchor accessory installation is required.
