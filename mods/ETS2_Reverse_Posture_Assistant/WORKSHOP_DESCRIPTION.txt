[h1]v1.62.1 — ETS2 1.62.x compatibility / 欧卡 2 1.62.x 适配[/h1]

[h1]English[/h1]
Reverse Posture Assistant adds world-space reverse guidance: two blue tractor boundaries and two orange trailer boundaries over a fixed 5 m prediction path. The curves follow steering and articulation, using wheel contact, lift state and steerable axle angles. Prediction lines appear only in reverse gear and hide while paused.

[b]What changed in v1.62.1[/b]
[list]
[*]Adds an exact native profile for the ETS2 1.62.2.1 Steam public executable and retains the exact 1.62.1.0 profile.
[*]Adds verified RVAs and signatures for four native hooks and four active model-lifecycle helpers.
[*]Keeps unknown or mismatched game builds fail-closed in telemetry-only mode.
[*]Retains supported ETS2 1.61.x and 1.60.x profiles and the existing reverse prediction behavior.
[*]Starts the game-aligned mod version scheme: releases use v1.62.x from this version onward.
[*]Keeps Reverse Planner separate; its compatibility is handled by its own release.
[/list]

[b]Installation / upgrade[/b]
1. Exit ETS2 and let Steam download this item's latest content.
2. Download v1.62.1 Runtime for Workshop, extract it and run Install-Runtime-Only.bat.
[url=https://github.com/yyysheng/ETS2mods/releases/download/reverse-posture-assistant-v1.62.1/ETS2_Reverse_Posture_Assistant_v1.62.1_Runtime_for_Workshop.zip]Download Runtime for Workshop v1.62.1[/url]
3. Enable this Workshop item in the Mod Manager. Disable older local copies of Reverse Posture Assistant, then restart the game.

[b]A Workshop subscription alone cannot install the required DLL. Update the runtime DLL and Workshop content together.[/b]
For standalone installation, use the Full package instead of subscribing; do not enable both copies:
[url=https://github.com/yyysheng/ETS2mods/releases/tag/reverse-posture-assistant-v1.62.1]v1.62.1 downloads and release notes[/url]
If Steam hides the link, search GitHub for yyysheng/ETS2mods and open Releases.

Compatibility: ETS2 1.62.*, 1.61.* and 1.60.*, Windows x64. Exact native profiles are included for 1.62.1.0, 1.62.2.1, 1.61.1.0, 1.61.1.1 and 1.61.1.9; other unmatched builds safely use telemetry-only mode. No camera, mirror, depth-buffer or rendered-image capture; no bundled dxgi.dll or d3d11.dll. No Reverse Assist Anchor accessory installation is required.
