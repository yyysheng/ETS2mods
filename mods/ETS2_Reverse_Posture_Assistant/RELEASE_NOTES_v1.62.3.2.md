# ETS2 Reverse Posture Assistant v1.62.3.2

本版面向 ETS2 1.62.3.2 Steam Windows x64（f8b10df2da6f）。原生运行组件校验可执行文件 SHA-256、四个 Hook 与四个模型生命周期辅助函数的签名。其他构建进入仅遥测模式。

完整包包含 .scs 和原生遥测 DLL。工坊用户需配套安装相同版本的 Runtime for Workshop。安装前请保存并退出游戏。

The native runtime targets ETS2 1.62.3.2 Steam Windows x64 (f8b10df2da6f). It checks the exact executable SHA-256, four hook signatures and four model-lifecycle helper signatures. Close the game before installing the Full package or the Workshop runtime.
