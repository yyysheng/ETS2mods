# Multi-project licensing index

Each mod has its own LICENSE scope index, preserved historical MIT text, LICENSE_HISTORY.md and THIRD_PARTY_NOTICES.md. There is no repository-wide blanket license. Historical MIT covered original project code in its then-applicable scope; models/assets are reviewed separately and are not retroactively designated MIT or proprietary.

FUTURE_LICENSING_POLICY.md in each mod permits prospective relicensing of original code with full authority, including previously MIT-published original code, while preserving past grants and third-party rights. No proprietary switch is active.

Public build inputs include LICENSE_PACKAGE.json, effective texts/notices, the game manifest and packaging scripts. The LF-canonical historical hash convention is documented in LICENSE_SCOPE.md. Private ownership inventories, audit evidence and inactive detailed drafts are outside this repository and are not needed for packaging.

Scope: ETS2 Posture Assistant v0.10.7 through v1.62.3.3; ATS v0.10.8 through v0.11.3; ReversePlanner separately. v0.6.0 is excluded.
